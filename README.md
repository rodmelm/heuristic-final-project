# heuristic-final-project
An advanced algorithmic project combining C++ and Python to implement, optimize, and evaluate heuristic search algorithms on complex graph structures

(Developed as an assignment for my Computer Engineering degree)

This project focuses on algorithmic efficiency and data structure management. It implements heuristic search algorithms (managing Open and Closed lists) to find optimal paths within weighted graphs.

The architecture uses C++ for optimization (ensuring maximum execution speed and efficient memory management) and Python for data parsing, automation, and testing.

Built With C++ and python

Key Technical Highlights

  - Custom Graph Implementation: Built a robust graph data structure from scratch in C++ to handle nodes, edges, and heuristic weights without relying on heavy external libraries.
  
  - State Space Search: Efficient implementation of heuristic algorithms (similar to A*) using optimized Open/Closed list management to prevent infinite loops and reduce time complexity.
  
  - Polyglot Architecture: Seamlessly bridging Python scripts for .in / .out file handling with a compiled C++ binary for high-speed algorithmic calculations.
